## 1. 历史背景

巴特沃斯滤波器由英国物理学家 **Stephen Butterworth**（1885–1958）于 **1930年** 在英国物理学期刊上发表的论文 *"On the Theory of Filter Amplifiers"* 中首次提出。

该滤波器的核心创新在于：**在通带内实现最大平坦的幅度响应**，即在 ω = 0 处，幅频响应的前 (2n−1) 阶导数全部为零，使得滤波器在通带范围内对信号幅度的扭曲最小。

## 2. 核心数学原理

### 2.1 幅度平方响应

巴特沃斯滤波器的幅度平方函数定义为：

$$
|H(j\omega)|^2 = \frac{1}{1 + \left(\frac{\omega}{\omega_c}\right)^{2n}}
$$

其中：

| 符号 | 含义 | 说明 |
|------|------|------|
| $n$ | 滤波器阶数（order） | 正整数，决定滤波器的滚降陡峭度 |
| $\omega$ | 信号角频率 | 单位：rad/s |
| $\omega_c$ | 截止频率（-3dB 频率点） | 幅度衰减到 $\frac{1}{\sqrt{2}} \approx 0.707$ 的频率 |
| $j$ | 虚数单位 | $j^2 = -1$ |

**关键性质验证：**

- 当 $\omega = 0$ 时：$|H|^2 = \frac{1}{1+0} = 1$（通带内无衰减）
- 当 $\omega = \omega_c$ 时：$|H|^2 = \frac{1}{1+1} = \frac{1}{2}$（恰好 -3dB）
- 当 $\omega \to \infty$ 时：$|H|^2 \to 0$（高频被完全衰减）

### 2.2 s 域传递函数

将幅度平方函数解析延拓到复频域，得到巴特沃斯滤波器的传递函数：

$$
H(s) = \frac{1}{B_n(s)}
$$

其中 $B_n(s)$ 是 **n 阶巴特沃斯多项式**。其极点分布在 s 平面单位圆的**左半部分**（保证稳定性）：

$$
p_k = -\sin\left(\frac{(2k-1)\pi}{2n}\right) + j\cos\left(\frac{(2k-1)\pi}{2n}\right), \quad k = 1, 2, \ldots, n
$$

### 2.3 低阶巴特沃斯多项式

| 阶数 $n$ | 巴特沃斯多项式 $B_n(s)$ | 极点位置 |
|:---------:|:------------------------|:---------|
| 1 | $s + 1$ | $-1$ |
| 2 | $s^2 + \sqrt{2}\,s + 1$ | $-\frac{\sqrt{2}}{2} \pm j\frac{\sqrt{2}}{2}$ |
| 3 | $(s+1)(s^2 + s + 1)$ | $-1,\; -\frac{1}{2} \pm j\frac{\sqrt{3}}{2}$ |
| 4 | $(s^2 + 0.7654s + 1)(s^2 + 1.8478s + 1)$ | 四个共轭极点均匀分布于左半圆 |

### 2.4 从幅度平方到传递函数

推导过程如下：

1. 将 $s = j\omega$ 代入幅度平方函数：

$$
|H(j\omega)|^2 = H(j\omega) \cdot H^*(j\omega) = H(j\omega) \cdot H(-j\omega)
$$

2. 令 $s = j\omega$，即 $\omega = s/j$：

$$
H(s) \cdot H(-s) = \frac{1}{1 + \left(\frac{s}{j\omega_c}\right)^{2n}} = \frac{1}{1 + \left(\frac{-s^2}{\omega_c^2}\right)^{n}}
$$

3. 分解该表达式，选择**左半平面极点**构成因果稳定系统 $H(s)$。

### 2.5 分贝表示

幅度响应的分贝形式：

$$
|H(j\omega)|_{\text{dB}} = 10 \log_{10}\left(\frac{1}{1 + (\omega/\omega_c)^{2n}}\right) = -10\log_{10}\left(1 + (\omega/\omega_c)^{2n}\right)
$$

**特殊频率点：**

| 频率 | $|H|_{\text{dB}}$ | 说明 |
|------|:---:|------|
| $\omega = 0$ | $0$ dB | 无衰减 |
| $\omega = \omega_c$ | $-3.01$ dB | -3dB 截止点 |
| $\omega = 2\omega_c$ | $-12.04n_1$ dB（$n=1$ 时） | -3dB 点的一倍频处 |
| $\omega = 10\omega_c$ | $\approx -20n$ dB | 十倍频衰减 |

### 3.3 相频响应

巴特沃斯滤波器的相位响应为：

$$
\phi(\omega) = -\sum_{k=1}^{n} \arctan\left(\frac{\omega - \omega_k'}{\omega_k''}\right)
$$

其中 $\omega_k' + j\omega_k''$ 是第 $k$ 个极点。

群延迟（group delay）：

$$
\tau_g(\omega) = -\frac{d\phi}{d\omega}
$$

## 6. SOS 二阶级联实现

### 6.1 为什么用 SOS（Second-Order Sections）？

高阶滤波器直接实现会面临**数值稳定性**问题。SOS 将 n 阶滤波器分解为多个二阶段的级联：

$$
H(s) = \prod_{k=1}^{M} H_k(s) = H_1(s) \cdot H_2(s) \cdots H_M(s)
$$

其中 $M = \lceil n/2 \rceil$，每段 $H_k(s)$ 的形式为：

$$
H_k(s) = \frac{b_{0k} + b_{1k}s^{-1} + b_{2k}s^{-2}}{1 + a_{1k}s^{-1} + a_{2k}s^{-2}}
$$

### 6.2 SOS 的优势

```
  直接实现 n 阶滤波器          SOS 级联实现
  ┌───────────────────┐      ┌─────────┐  ┌─────────┐  ┌─────────┐
  │                   │      │ H₁(z)   │→ │ H₂(z)   │→ │ H₃(z)   │
  │  n 阶差分方程      │      │ 二阶级 1 │  │ 二阶级 2 │  │ 二阶级 3 │
  │                   │      └─────────┘  └─────────┘  └─────────┘
  │  ❌ 系数精度敏感    │
  │  ❌ 溢出风险高      │      ✅ 每段独立，数值稳定
  │  ❌ 舍入误差累积    │      ✅ 溢出限制在单段内
  └───────────────────┘      ✅ 每段系数范围温和
```

```c
// SOS 滤波核心 —— 每个 ADC 样本调用一次
int32_t sosfilt(struct sos_filter *sf, const int32_t unfiltered_value) {
    fixedQ_value_t cur_val = unfiltered_value;
    for (int i = 0; i < sf->n_sections; i++) {
        struct sos_filter_section *section = &(sf->filter[i]);
        // Direct Form II Transposed 结构
        fixedQ_value_t next_val = fixed_mul(sf, section->coeff[0], cur_val);
        next_val += section->state[0];
        section->state[0] = fixed_mul(sf, section->coeff[1], cur_val)
                          - fixed_mul(sf, section->coeff[3], next_val)
                          + section->state[1];
        section->state[1] = fixed_mul(sf, section->coeff[2], cur_val)
                          - fixed_mul(sf, section->coeff[4], next_val);
        cur_val = next_val;
    }
    return (int32_t)cur_val;
}
```

### 7.2 六大选择理由

#### 理由一：通带无纹波 — 力测量幅度精度是生命线

称重传感器探头的核心任务是**精确测量喷嘴接触热床时的力值**。

```
  有纹波的滤波器（如 Chebyshev）       无纹波的滤波器（Butterworth）
  ┌───────────────────────────┐       ┌───────────────────────────┐
  │ 力  ↑   ╭╮                │       │ 力  ↑                    │
  │     │  ╱  ╲ ╭╮            │       │     │                    │
  │     │ ╱    ╲╱ ╲╭╮         │       │     │  ━━━━━━━━━━━━━━━━  │ ← 真实力值
  │     │╱        ╲  ╲━━━━━   │       │     │                    │
  │     ┼──────────────────→  │       │     ┼──────────────────→ │
  │         时间               │       │         时间              │
  │                            │       │                            │
  │ ❌ 滤波后力值有"假波动"       │       │ ✅ 滤波后力值平滑真实       │
  │    → 触发阈值判断不可靠       │       │    → 触发精度有保证         │
  └───────────────────────────┘       └───────────────────────────┘
```

切比雪夫和椭圆滤波器的通带等纹波在此场景下是致命缺陷：纹波会被误读为力的波动，导致触发位置不一致。

#### 理由二：单调衰减 — 安全检测可预测

Kalico 有两层安全保护：

| 安全机制 | 配置参数 | 默认值 | 作用 |
|---------|---------|--------|------|
| 力安全限制 | `force_safety_limit` | 2000g | 探测前检查：防止在过大外力下探测 |
| 漂移安全限制 | `drift_safety_limit` | 1000g | 探测中检查：防止过大力导致损坏 |

巴特沃斯滤波器在通带和阻带**都是单调衰减**，没有起伏。安全阈值的行为是**完全可预测**的。

```
  巴特沃斯（单调衰减）               椭圆滤波器（阻带有纹波）
  ┌─────────────────────┐         ┌─────────────────────┐
  │ 增益↑               │         │ 增益↑     ╭╮        │
  │      ━━━━━╲         │         │      ━━━━╲╱╲╭╮      │
  │           ╲         │         │           ╲  ╲       │
  │            ╲━━━━━━━ │         │            ╲╱  ╲━━━  │
  │     ┼──────┼─────→  │         │     ┼──────┼────→   │
  │    ωc   安全区       │         │    ωc   安全区      │
  │                      │         │                      │
  │ ✅ 安全区内无噪声逃逸  │         │ ❌ 纹波峰可能误触发   │
  └─────────────────────┘         └─────────────────────┘
```

#### 理由三：阶跃响应良好 — 轻敲波形保真

Kalico 对每次探针接触进行**完整波形分析**（见 [tap_analysis.py](../kalico/klippy/extras/load_cell/tap_analysis.py)）。轻敲波形分解为 5 条线段：

```
  力 (g)
  ↑
  │            p2━━━━━━p3           ← 停留阶段 (dwell)
  │           ╱          ╲
  │          ╱ L2    L3    ╲ L4
  │         ╱              ╲
  │   p1━━━╱                ╲
  │   ↑ ╱ L1                 ╲━━━p5 → p0 (离开)
  │   │╱                       ╲
  p0━━╱                         ╲━━━━━
  │
  ├──────┼──────┼──────┼──────┼──────→ 时间
       接触    峰值   开始回抽  断开接触

  L1: 趋近线 (approach)
  L2: 压缩线 (compression)
  L3: 停留线 (dwell)
  L4: 解压线 (decompression)
  L5: 离开线 (departure)

  ★ p4（L4 与 L5 的交点）= Z=0 参考点
```

如果滤波器引入振铃（ringing），会扭曲这些线段的形状，导致：
- 肘点位置偏移 → Z 轴定位不准
- 轻敲验证失败（`TAP_SHAPE_INVALID`、`TAP_BREAK_CONTACT_TOO_LATE`）

```
  无振铃（Butterworth）               有振铃（Elliptic）
  ┌──────────────────────┐         ┌──────────────────────┐
  │ 力↑    ╭━━━━╮        │         │ 力↑   ╭~~━━~~╮       │
  │       ╱      ╲       │         │      ╱~      ~╲      │
  │      ╱        ╲      │         │     ╱~        ~╲     │
  │    ╱            ╲     │         │   ╱~    振铃    ~╲   │
  │  ╱                ╲   │         │ ╱~                ~╲ │
  │ ┼────────────────→  │         │ ┼────────────────→  │
  │                      │         │                      │
  │ ✅ 肋点清晰准确       │         │ ❌ 肋点被振铃模糊      │
  └──────────────────────┘         └──────────────────────┘
```

#### 理由四：适合 MCU 定点运算

Kalico 的滤波器运行在**资源受限的 MCU** 上（ARM Cortex-M0+），使用 Q2.29 和 Q16.15 定点数运算。

巴特沃斯滤波器的**系数值温和**（不像椭圆滤波器有接近极点的系数需要极高精度）：

| 滤波器 | 典型系数范围 | 定点量化误差影响 |
|--------|:----------:|:---------------:|
| 巴特沃斯 4 阶 | 0.38 ~ 1.85 | 小 ✅ |
| 切比雪夫 4 阶 | 0.01 ~ 2.50 | 中等 ⚠️ |
| 椭圆 4 阶 | 0.001 ~ 3.20 | 大 ❌ |

在 32 位整数精度下，巴特沃斯系数的量化误差对滤波器特性的影响最小，数值稳定性最好。

#### 理由五：高通 + 低通组合的完美搭档

从 [load_cell_probe.py](../kalico/klippy/extras/load_cell/load_cell_probe.py:228) 的 `ContinuousTareFilter` 可以看到，Kalico 设计了灵活的组合滤波架构：

```python
class DigitalFilter:
    def __init__(self, sps, error_func,
                 highpass=None, highpass_order=1,     # 高通：去除漂移
                 lowpass=None, lowpass_order=1,       # 低通：去除高频噪声
                 notches=None, notch_quality=2.0):    # 陷波：去除特定频率
```

配置参数示例：

| 参数 | 用途 | 典型值 |
|------|------|--------|
| `drift_filter_cutoff_frequency` | 漂移高通截止频率 | 0.5 Hz |
| `drift_filter_delay` | 高通滤波器阶数 | 2 |
| `buzz_filter_cutoff_frequency` | 振动低通截止频率 | 80+ Hz |
| `buzz_filter_delay` | 低通滤波器阶数 | 2 |
| `notch_filter_frequencies` | 陷波频率 | [50, 100] Hz |
| `notch_filter_quality` | 陷波 Q 值 | 2.0 |

巴特沃斯的高通和低通设计方式完全对称，参数化配置简洁，非常适合这种灵活的多段组合架构。

#### 理由六：行业标准与可复现性

| 设备 | 滤波器类型 | 截止频率 | 说明 |
|------|-----------|---------|------|
| Prusa MK4 | Butterworth | 0.8 Hz | 漂移补偿 |
| Prusa XL | Butterworth | 11.2 Hz | 工具头多传感器 |
| Kalico | Butterworth | 0.1~20 Hz | 可配置范围 |

巴特沃斯是信号处理领域**最广泛使用和理解的滤波器类型**。选择它意味着：
- 用户调参时有大量参考资料
- 不同打印机之间的参数可移植
- 与其他开源固件兼容

### 7.3 为什么不选其他滤波器？

| 被排除的滤波器 | 致命原因 | 影响 |
|---|---|---|
| **Chebyshev I 型** | 通带等纹波 → 力值幅度失真 | 触发阈值不一致，Z 精度下降 |
| **Chebyshev II 型** | 阻带纹波 → 特定噪声逃逸 | 安全检测不可靠 |
| **椭圆滤波器** | 阶跃响应振铃严重 + 系数敏感 | 轻敲波形被破坏，定点实现困难 |
| **Bessel 滤波器** | 滚降太慢（-20n dB/dec 最低） | 无法过滤 100-1000 Hz 的电机振动 |
| **移动平均** | 频率选择性差，无法精确设定截止频率 | 不能区分信号和噪声频率 |
| **中值滤波** | 不平滑，不适用于连续力信号 | 无法跟踪鲍登管漂移趋势 |

### 7.4 选择决策树

```
  Load Cell 探头需要什么？
  │
  ├── ① 通带幅度精确？ ──→ 排除 Chebyshev I、椭圆
  │
  ├── ② 阻带单调衰减？ ──→ 排除 Chebyshev II、椭圆
  │
  ├── ③ 阶跃响应干净？ ──→ 排除椭圆、Chebyshev
  │
  ├── ④ 滚降足够快？   ──→ 排除 Bessel
  │
  ├── ⑤ 系数温和？     ──→ 排除椭圆（定点 MCU 友好性）
  │
  └── ⑥ 行业标准？     ──→ Prusa 也用巴特沃斯
          │
          ▼
      ┌─────────────┐
      │ Butterworth │  ← 唯一满足所有条件的滤波器
      └─────────────┘
```

## 8. 总结

巴特沃斯滤波器是 Kalico Load Cell 探头的最佳选择，其三个核心特性完美匹配探头应用的三个核心需求：

| 巴特沃斯特性 | 探头需求 | 代码体现 |
|---|---|---|
| **通带最大平坦** | 力测量幅度不失真 | `scipy.signal.butter()` → SOS 格式 |
| **单调衰减无纹波** | 安全阈值可预测 | `force_safety_limit` / `drift_safety_limit` |
| **适中的阶跃响应** | 轻敲波形保持完整 | `TapAnalysis` 肘点检测精度 |

加上以下工程优势：

- ✅ 系数温和，适合 32 位定点 MCU 实现
- ✅ 可与高通、低通、陷波器灵活组合
- ✅ 是行业标准（Prusa 等也采用）
- ✅ 参数可移植、文档丰富

这些因素共同决定了巴特沃斯滤波器在 Kalico 称重传感器探头中的不可替代地位。
