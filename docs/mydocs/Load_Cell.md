# 称重传感器

本文档描述称重传感器（Load Cell）的支持。称重传感器通过 ADC（模数转换器）测量施加到应变片上的力。它们可用于读取力数据、称量物体（如线材卷轴），或作为探针使用。

警告：使用称重传感器之前必须进行校准。如果校准不正确，报告的力/重量将不准确，这可能会导致称重传感器和/或打印机的永久性损坏。本模块无法补偿不良校准、损坏的应变片或电气噪声。

## 基本称重传感器配置

称重传感器可以配置为秤使用。

```ini
[load_cell]
sensor_type: hx717
sclk_pin: PA5
dout_pin: PA4
sample_rate: 320
counts_per_gram: 245
reference_tare_counts: 12345
```

- `sensor_type: hx717`\
  _必填_\
  每种传感器有不同的必填字段，请查阅其配置参考获取详细信息：

  * [`hx711`](../Config_Reference.md#hx711)
  * [`hx717`](../Config_Reference.md#hx717)
  * [`ads1220`](../Config_Reference.md#ads1220)
  * [`ads131m02`](../Config_Reference.md#ads131m02)
  * [`ads131m04`](../Config_Reference.md#ads131m04)

- `counts_per_gram: 245`\
  _默认值：无_\
  从原始传感器计数到克的转换系数，由 `LOAD_CELL_CALIBRATE` 计算得出。

- `reference_tare_counts: 12345`\
  _必填_\
  以原始传感器计数表示的基线皮重值，由 `LOAD_CELL_CALIBRATE` 设置。

## 诊断

### 检查称重传感器工作状态

`LOAD_CELL_DIAGNOSTIC`（[文档](../G-Codes.md#load_cell_diagnostic)）

从称重传感器采集样本并报告健康状况和统计数据。首次连接称重传感器时运行此命令以验证接线和配置。

```
LOAD_CELL_DIAGNOSTIC
// Collecting load cell data for 10 seconds...
// Samples Collected: 3211
// Measured samples per second: 332.0
// Good samples: 3211, Saturated samples: 0, Unique values: 900
// Sample range: [4.01% to 4.02%]
// Sample range / sensor capacity: 0.00524%
```

检查输出：
- 每秒采样数应接近配置的 `sample_rate`。如果不接近，请检查配置。对于 HX711，采样率由硬件决定。
- 饱和样本数应为 0。非零值表示施加了超出传感器测量范围的过大力。
- 唯一值应占采集样本的较大百分比。如果唯一值为 1，请检查接线。
- 在测试期间轻敲或推动传感器。如果传感器工作正常，样本范围应增大。

## 校准

### 校准称重传感器

`LOAD_CELL_CALIBRATE`（[文档](../G-Codes.md#load_cell_calibrate)）

启动交互式校准工具。校准过程包含三个步骤：

1. `TARE` — 建立零力值并设置 `reference_tare_counts`
2. `CALIBRATE GRAMS=<value>` — 施加已知力并计算 `counts_per_gram`
3. `ACCEPT` — 将校准结果保存到配置

使用 `ABORT` 可随时取消校准。

校准后运行 `LOAD_CELL_DIAGNOSTIC` 将显示以克为单位的附加信息。

#### 施加已知力

`CALIBRATE GRAMS=<value>` 步骤需要施加已知力。方法取决于称重传感器的安装位置：

**平台安装的称重传感器**（位于热床下方或线材支架下方）：
将已知质量的物体放在平台上。理想情况下，使用称重传感器额定量程的较大百分比（例如，5 kg 的称重传感器使用 5 kg 的物体）。

**工具头称重传感器**：
将电子秤放在热床上，轻轻将工具头降低到电子秤上（如果热床可移动则升起热床）。使用至少 1 kg 的力。过大的力可能损坏热床或工具头，因此请小步移动。从电子秤读取读数并输入到 `CALIBRATE GRAMS=<value>` 命令中。

#### 理解校准结果

```
CALIBRATE GRAMS=555
// Calibration value: -2.78% (-559467), Counts/gram: 87.944082,
Total capacity: +/- 29.14Kg
```

`Calibration value:` 显示校准使用了传感器量程的百分比。

`Counts/gram:` 是等于 1 克力的传感器计数数量。此数值越大，秤的精度越高。

`Total capacity` 是传感器能记录的最高力值。`Total capacity` 应接近称重传感器的额定量程。如果大很多，请考虑使用更高增益设置或更灵敏的称重传感器。这对于低于 24 位位宽的传感器更为关键。

## 操作

### 读取力数据

`LOAD_CELL_READ`

读取称重传感器上的当前力值。

```
LOAD_CELL_READ
// 10.6g (1.94%)
```

力数据也可在 `load_cell` 打印机对象中获取：

```gcode
{% set grams = printer.load_cell.force_g %}
```

此值是最近 1 秒的平均值，类似于温度传感器。

### 称重传感器去皮

`LOAD_CELL_TARE`

将当前读数设置为零力。适用于测量相对重量变化，例如打印过程中的线材消耗。

```
LOAD_CELL_TARE
// Load cell tare value: 5.32% (445903)
```

去皮值可在 `load_cell` 打印机对象中获取：

```gcode
{% set tare_counts = printer.load_cell.tare_counts %}
```

## 称重传感器探针配置

此示例为已校准的称重传感器添加探针功能。`[load_cell_probe]` 配置段包含所有 `[load_cell]` 参数、称重传感器探针专用参数和 [`[probe]`](../Config_Reference.md#probe) 参数。

```ini
[load_cell_probe]
# load cell settings
sensor_type: hx717 # sensor specific config
counts_per_gram: 245
reference_tare_counts: 12345
# load cell probe settings
trigger_force: 75
force_safety_limit: 2000
drift_safety_limit: 1000
drift_filter_cutoff_frequency: 0.5
# probe settings
z_offset: 0.0
```
- `sensor_type: hx717`
- `counts_per_gram: 245`\
  与基本称重传感器相同
- `reference_tare_counts: 12345`\
  _默认值：无_\
  以原始传感器计数表示的基线皮重值，由 `LOAD_CELL_CALIBRATE` 设置。用作 `force_safety_limit` 的零值，以定义安全工作范围。

- `trigger_force: 75`\
  _默认值：75（75 克）_\
  探针探测时触发限位开关的力（以克为单位），相对于探测开始时的皮重值测量。预期会有过冲；更高的探测速度或更低的采样率会增加峰值力。有关多 MCU 时序注意事项，请参见 [多 MCU 归位](../Multi_MCU_Homing.md)。75g 的默认值是保守的。更高的值（最高 200g）可以在处理溢料较多的线材时提高性能。

- `force_safety_limit: 2000`\
  _默认值：2000（±2Kg）_\
  要安全开始探测移动，探针上的力必须低于此限制。它将 `reference_tare_counts` 作为其零值。可以通过将值设置为 0 来禁用此检查。如果超出，探针将停止并显示错误 `!! Load Cell Probe Error: force of 3000g exceeds force_safety_limit (2000g) before probing!`。此值需要足够大以允许：
  - 鲍登管和拖链力，这些力在整个打印体积和探测移动长度中会变化
  - 在整个探测温度范围内的温度漂移

- `drift_safety_limit: 1000`\
  _默认值：1000（±1Kg）_\
  这是探针在触发错误之前探测移动期间允许的最大力。设置为 0 可禁用此安全检查。如果超出，探针将停止并显示错误 `!! Load Cell Probe Error: force exceeded drift_safety_limit before triggering!`。在使用 `drift_filter_cutoff_frequency` 时此安全措施很重要，因为过高的截止频率可能会阻止探针触发。

- `drift_filter_cutoff_frequency: 0.5`\
  _默认值：无（禁用）_\
  连续去皮漂移滤波器的截止频率（单位：Hz）。在 MCU 上启用滤波器以跟踪鲍登管和拖链引起的漂移。需要 [SciPy](#安装-scipy)。将此值设置得过高会延迟探针触发并增加工具头上的力。

- `z_offset: 0.0`\
  _必填_\
  探针触发时热床与喷嘴之间的距离（以 mm 为单位）。对于称重传感器探针，此值为 0。

有关所有可用选项，请参见[配置参考](../Config_Reference.md#load_cell_probe)。

### 安全

称重传感器是直接喷嘴接触式探针。系统包含安全检查以防止工具头受力过大。选择不当的配置值可能会破坏这些保护措施。

**校准检查：**
在归位或探测之前，称重传感器探针会检查是否已校准。如果没有，打印机将停止并显示错误 `!! Load Cell Probe Error: Load Cell not calibrated`。

**准确的 `counts_per_gram`：**
此设置将原始计数转换为克。所有安全限制都以克为单位。不准确的值会导致工具头受力过大。切勿猜测此值——始终使用 `LOAD_CELL_CALIBRATE`。

**保守的 `trigger_force`：**
探测时总是在停止前超过 `trigger_force`。设置为 100 g 可能导致 350 g 的峰值力。过冲随着探测速度加快、采样率降低或多 MCU 配置而增大。

**`force_safety_limit` 保护：**
此设置在开始归位或探测之前检测探针上的过大受力。如果超出限制，探针将停止并显示错误，例如 `!! Load Cell Probe Error: force of 3000g exceeds force_safety_limit (2000g) before probing!`。这可能是由于以下原因：
- 探针在探测开始前与热床碰撞，例如水平移动撞到倾斜的热床
- 鲍登管或拖链的过大受力
- 挤出机推线材导致应变片受力过大
- 应变片损坏，导致零点远离 `reference_tare_counts` 值

**`drift_safety_limit` 保护：**
此设置定义探针在触发前允许的最大力。如果测量的力变化超过限制，探针将停止并显示错误：`!! Load Cell Probe Error: force exceeded drift_safety_limit before triggering!`。这可能是由于以下原因触发的：
- 探测时探针被主动加热，导致皮重值漂移
- `drift_filter_cutoff_frequency` 设置过高，导致轻敲事件被滤除
- 探测时鲍登管/拖链力的大幅变化

**看门狗任务：**
在归位期间，看门狗监控传感器数据。如果传感器在 2 个采样周期内未能发送测量数据，MCU 将关闭并显示错误 `!! Load Cell Probe Error: timed out waiting for sensor data`。这通常表示 ADC 故障或接地不足。确保机架、电源和打印床接地。可能需要多个接地连接。在接地连接点处打磨阳极氧化铝以获得良好的电气接触。

**轻敲验证和重试：**
探针验证每次轻敲的形状、断开接触时序和运动时序。无效轻敲将被拒绝（`is_valid=False`），并根据探针配置的 `bad_probe_strategy` 和 `bad_probe_retries` 进行重试。这可以防止接受受污染或质量差的轻敲。有关验证失败类型，请参见[轻敲验证错误代码](#轻敲验证错误代码)。请注意，验证能捕获许多但不是全部的不良轻敲，适当的喷嘴温度和清洁度仍然至关重要。

### 测试探针操作

`LOAD_CELL_TEST_TAP [COUNT=<taps>] [TIMEOUT=<seconds>]`\
_默认 COUNT：3_\
_默认 TIMEOUT：30_

测试探针操作而不移动轴。检测指定次数的轻敲后结束。如果在超时时间内未检测到轻敲，命令将失败。命令验证轻敲质量并将验证错误记录到控制台。

**注意：** 称重传感器探针不支持 `QUERY_ENDSTOPS` 或 `QUERY_PROBE`，它们始终返回未触发状态。在探测之前使用 `LOAD_CELL_TEST_TAP` 验证功能。

### 归位配置

称重传感器探针支持 Z 轴归位。归位比使用 `PROBE` 命令探测精度低。归位后，使用 `PROBE` 进行高精度 Z 轴归位：

```gcode
PROBE HOME=Z
```

### 探测温度

在归位和探测期间保持喷嘴温度低于线材溢出温度。140°C 是所有线材类型的合理起点。

线材溢出是探测误差的主要来源。Kalico 验证轻敲质量并拒绝许多不良轻敲（例如由溢料引起的）。防止溢料和保持喷嘴清洁仍是最佳实践。不建议在打印温度下探测。注意控制台上的轻敲验证错误（例如 `TAP_SHAPE_INVALID`、`TAP_BREAK_CONTACT_TOO_LATE`），这些错误表示轻敲质量差。

### 喷嘴保护

请参见 [Voron Tap 的 activate_gcode](https://github.com/VoronDesign/Voron-Tap/blob/main/config/tap_klipper_instructions.md) 以保护打印表面免受热喷嘴的损害。

### 喷嘴清洁

探测前清洁喷嘴。建议步骤：
1. 将喷嘴加热到探测温度（例如 `M109 S140`）
2. 机器归位（`G28`）
3. 擦洗喷嘴
4. 热浸泡热床
5. 执行探测任务（QGL、热床网格等）

### 喷嘴温度补偿

由于溢料，无法在打印温度下进行探测。探测后喷嘴被加热，导致其膨胀。喷嘴沿其长度方向（朝向热床）膨胀最多。应使用 [z_thermal_adjust](../Config_Reference.md#z_thermal_adjust) 进行补偿。

在两个温度下（例如 180°C 和 290°C）测量 `PROBE_ACCURACY` 并计算：

```
temp_coeff = (z_average_hot - z_average_cold) / (temp_hot - temp_cold)
```

示例：`temp_coeff = -0.05 / (290 - 180) = -0.00045455`

预期为负值（`z_thermal_adjust` 将在负值时使喷嘴远离热床，在正值时使喷嘴靠近热床）。

示例配置：

```ini
[z_thermal_adjust nozzle]
temp_coeff: -0.00045455
sensor_type: temperature_combined
sensor_list: extruder
combination_method: max
min_temp: 0
max_temp: 400
max_z_adjustment: 0.1
```

### 热床网格设置

**禁用 `relative_reference_index`**
因为称重传感器探针提供绝对的 z 值，不相对于任何参考点，所以不需要 `relative_reference_index`。只需在 `[bed_mesh]` 中删除该设置。从配置中删除该行即可关闭它。

**启用激进的移动分割**
```ini
move_check_distance: 3.0
split_delta_z: 0.01
```
设置网格以尽可能频繁地调整 z 高度。这两个设置改变了热床网格评估 z 变化的方式。最小化 `split_delta_z` 以获得高分辨率的网格跟踪（0.01 是 10 微米，是探针分辨率的 10 倍）。为 `move_check_distance` 选择较小的值会迫使 bed_mesh 更频繁地重新评估 z 高度。如果这些设置保持默认值，您可能会在第一层看到由于不频繁调整而产生的条纹。

**启用 `horizontal_z_clearance`**
```ini
horizontal_z_clearance: 0.4
```
使用 `horizontal_z_clearance`，探针始终在网格点之间回缩该量。这可以大大减少适应热床形状时的 z 移动距离。更少的移动距离可以加快探测速度。

**在网格化之前使用 NOZZLE_CLEANUP**
```
NOZZLE_CLEANUP
```
此命令轻敲喷嘴直到报告连续 3 次成功的探测，证明喷嘴是清洁的。这在网格化之前清除喷嘴上的任何溢料，以获得最佳网格质量。应在打印区域外执行。请参见 [NOZZLE_CLEANUP](../G-Codes.md#nozzle_cleanup)

**使用 CIRCLE 策略进行网格化**
```
BED_MESH STRATEGY=CIRCLE
```
圆形策略是 `[probe]` 的一个功能。当称重传感器探针检测到受污染的探测时，它将以圆形图案移动到相邻位置。对于热床网格，这种轻微的位置偏移远不如使用受污染的探针严重。在受污染的位置重新探测不太可能成功，并可能导致网格化操作失败。

## 高级配置

### 连续去皮滤波

称重传感器探针支持在 MCU 上进行滤波，以补偿来自外部力（如鲍登管和电缆线束）的漂移。如果探针在接触热床之前就触发了，这可能就是原因。这有时被称为*连续去皮*，旨在用于工具头安装的传感器在探测过程中经历可变外部力的情况。

#### 安装 SciPy

滤波器默认关闭。需要 [SciPy](https://scipy.org/) 库从配置值计算滤波器系数。它需要安装在 Klipper 虚拟环境中。通常：

```bash
~/klippy-env/bin/pip install scipy
```

预编译版本适用于 32 位 Raspberry Pi 系统上的 Python 3。

#### 滤波器调参

`drift_filter_cutoff_frequency` 参数应根据正常操作期间观察到的漂移来选择。

基本调参指南：
- 从 `drift_filter_cutoff_frequency: 0.5` Hz 开始
- Prusa 使用 0.8 Hz（MK4）和 11.2 Hz（XL）；这个范围适合实验
- 仅在消除鲍登管漂移时才增加
- 设置过高会导致触发缓慢和过大的力
- 保持 `trigger_force` 较低（默认 75 g）；漂移滤波器将内部读数保持在零附近
- 调参期间保持 `force_safety_limit` 保守（默认 2 kg）
- 调参期间保持 `drift_safety_limit` 保守（默认 1 kg）
- **注意：** 过于激进的 `drift_filter_cutoff_frequency` 可能会扭曲轻敲形状和时序，导致验证失败（例如 `TAP_BREAK_CONTACT_TOO_LATE`）。如果出现此类错误，请降低截止频率或探测速度。

其他滤波器参数的调参超出了本文档的范围。
在 [scripts/filter_workbench.ipynb](../../scripts/filter_workbench.ipynb) 中提供了一个 Jupyter notebook，其中有详细分析的示例。

### 轻敲验证

**轻敲探测简介**

称重传感器探针的工作方式与其他探针不同，它在构建表面上进行"轻敲"。探针与构建表面接触后，会进行一小段远离构建表面的移动，称为回抽移动。这种向下/向上运动的组合称为一次"轻敲"。完整的轻敲序列会被分析，并从原始力数据构建一个表示。这个表示是由线段连接的一系列点。这是一个典型轻敲的图表，运动阶段已清楚标记：

##### 图 1：轻敲阶段
![显示探测、停留和回抽阶段的有效轻敲](../img/load-cell/tap-phases.png)

*图 1 — 有效的轻敲阶段。图表显示了测量力（黑线）随时间的变化以及拟合的验证线（红色）。三个阶段用颜色编码：探测（蓝色）——喷嘴接触热床时力上升；停留（绿色）——触发后力稳定；回抽（红色）——回抽移动抬起喷嘴时力回到基线。垂直线标记阶段边界：蓝色（探测结束/停留开始），绿色（停留结束/回抽开始），红色（回抽结束）。理想的轻敲在探测阶段显示急剧上升，在停留阶段力稳定，在回抽阶段干净地回到基线。*

图中的每条线都有名称：

##### 图 2：轻敲线段
![在实际力数据上标记的轻敲线段](../img/load-cell/tap-segments.png)

*图 1a — 轻敲图显示了命名的轻敲线段：趋近（接触前的平坦基线），压缩（力增大时的陡峭上升），停留（探针稳定时的稳定高力），**解压**（回抽期间的力下降），以及离开（回抽完成时回到基线）。彩色垂直线标记各阶段之间的边界。*

解压线和离开线的交点被探针报告为 Z=0 点。这是图上最关键的点。

回抽移动非常小（约 0.2mm）且非常慢。由于其慢速，解压线的斜率比压缩线更平缓。这提高了探针的精度，因为力随时间的变化更小，意味着探针的 z 分辨率提高了。本质上，回抽移动是对热床某一点的高分辨率力扫描。回抽移动由配置中的 `pullback_speed` 和 `pullback_dist` 选项控制。默认设置以每微米 1 个 ADC 样本的速率扫描，使探针的预期分辨率为 1 微米。

根据图表的形状可以判断探针是否良好。探针对点的顺序和线段形成的形状进行一些基本检查。如果不是"轻敲"形状，探针将被报告为不良。有关验证失败的详细信息，请参见[轻敲验证错误代码](#轻敲验证错误代码)。

#### 轻敲验证错误代码

当检测到质量差的轻敲时，会记录特定的错误代码。这些错误大多是喷嘴污染的症状，但有些可能表示配置或设置问题：

| 错误代码                      | 描述                                                                       | 常见原因                                                                                                              |
|-------------------------------|----------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------|
| `TAP_CHRONOLOGY`              | 轻敲图上的 4 个点在时间上不按顺序                                           | 污染：数据严重失真，看起来不像轻敲                                                                                    |
| `TAP_SHAPE_INVALID`           | 轻敲形状的某条线段方向不符合预期                                            | 污染：数据严重失真，看起来不像轻敲                                                                                    |
| `TAP_BREAK_CONTACT_TOO_EARLY` | 在回抽移动中过早检测到断开接触                                              | `pullback_distance` 过长。                                                                                           |
| `TAP_BREAK_CONTACT_TOO_LATE`  | 在回抽移动中过晚检测到断开接触                                              | `pullback_distance` 过短。                                                                                           |
| `TAP_PULLBACK_TOO_SHORT`      | 在回抽移动期间喷嘴始终未与热床断开接触                                      | `pullback_distance` 过短。                                                                                           |
| `COASTING_MOVE_ACCELERATION`  | 探测移动在探针触发前开始减速                                                | Z 未配置负的 `min_position` 以允许探针移动到 z=0 以下。例如：`position_min: -5`。                                     |
| `TOO_FEW_PROBING_MOVES`       | 梯形移动次数少于预期                                                        | 这种情况不常见                                                                                                       |
| `TOO_MANY_PROBING_MOVES`      | 梯形移动次数多于预期                                                        | 这种情况不常见                                                                                                       |

#### 轻敲质量

除了基本的轻敲形状检查外，一个称为**轻敲质量分类器**的模块为每次轻敲提供 0 到 100 的质量评分。分类器的主要目标是区分可用的干净轻敲和不可用的溢料轻敲。

分类器使用比例指标使其在不同打印机之间更具可移植性。它使用压缩线中总力的比例，因为这是轻敲中最佳的参考指标。这允许其他量随压缩力缩放。而绝对指标（角度、力）对于单一物理工具头设计和探测配置效果很好，但当这些条件改变时就会失效。

##### 轻敲质量组件

| 组件                           | 描述                                                                                                                                | 原因                                                                                                                    |
|--------------------------------|-------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------|
| 趋近力                         | 趋近线中力的变化除以压缩力。预期接近 0。                                                                                             | 趋近线中的大力与在接触热床之前撞到熔融塑料有关                                                                          |
| 离开力                         | 离开线中力的变化除以压缩力。预期接近 0。                                                                                             | 在此移动期间喷嘴应处于自由空气中，因此任何变形通常是由于溢料拉动喷嘴造成的。                                              |
| 基线力                         | 喷嘴与热床接触点和断开接触点之间的力差除以压缩力。预期接近 0。                                                                       | 当你移除重量时，秤应读数为零。大的差异表示施加了意外的力。                                                               |
| 停留力下降                     | 停留期间力的下降除以压缩力。                                                                                                         | 虽然一些下降并不罕见，但大幅下降与塑料从喷嘴和热床之间挤出有关。                                                         |
| 归一化解压角                   | 解压线的斜率与理想解压斜率的匹配程度。归一化为 `(实际 - 预期) / 预期`                                                                | 溢料会拉动喷嘴，改变斜率。这会破坏测量的精度。                                                                           |

这些因素综合起来给出最终的质量评分。唯一需要在打印机上测量的组件是**归一化解压角**。

每个组件都有最大截止值。如果组件超过截止值，轻敲质量评分会降至 0%。每个值都是压缩力的百分比：

| 组件         | 阈值  | 配置参数                    |
|--------------|-------|-----------------------------|
| 趋近力       | 50%   | max_approach_force=50       |
| 离开力       | 25%   | max_departure_force=25      |
| 基线力       | 25%   | max_baseline_force_delta=25 |
| 停留力下降   | 75%   | max_dwell_force_drop=75     |

#### 轻敲质量错误代码
如果默认的轻敲质量分类器处于活动状态，它可能会报告额外的错误代码：

| 错误代码                      | 描述                                                                     | 常见原因                                                                                                              |
|-------------------------------|--------------------------------------------------------------------------|-----------------------------------------------------------------------------------------------------------------------|
| `LOW_COMPRESSION_FORCE`       | 计算的压缩力小于 `trigger_force`                                         | 污染：喷嘴上的热塑料导致力上升非常缓慢。探测非常柔软的物体。                                                          |
| `LOW_TAP_QUALITY`             | 轻敲质量低于 `min_tap_quality` 设置                                      | 污染：轻敲特征可识别但已变形。`min_tap_quality` 配置过低。                                                             |

所有验证错误都会被记录以便排查问题。


## 开发者说明

本节介绍开发带有称重传感器探针支持的工具头板的指南。

### 轻敲分析和验证

称重传感器探针对每次探测尝试执行完整的轻敲分析。分析样本以识别轻敲点，并构建表示趋近、压缩、停留、解压和离开阶段的线段。点使用穷举肘部查找算法识别，线段使用线性回归构建。然后计算这些线段的交点，得到一组点。

参见[图 2](#图-2-低解压力) 和[图 3](#图-3-严重污染)

接下来执行一组基本的合理性检查：

1. **运动时序**：检查点是否按时间顺序排列。它们可能不按顺序，因为它们基于力数据、线性回归和交点。

2. **形状验证**：检查点是否形成"轻敲"形状的图表。可以是正梯形或负梯形形状。

3. **断开接触时序**：探针验证断开接触时间是否发生在回抽移动的中间三分之二内。过早或过晚都会使分析不太可靠。

如果任何这些检查失败，探针将被标记为不良。如果全部通过，则调用配置的 `TapClassifierModule` 进一步判断轻敲是好是坏。内置分类器称为 `TapQualityClassifier`，通过校准 `decompression_angle` 来启用。

**自定义轻敲分类器**：可以通过 `tap_classifier_module` 配置值用自定义实现完全替换内置的 `TapQualityClassifier`。分类器接收 `TapAnalysis` 对象，可以执行额外的验证或修改轻敲位置计算。使用适当的数据集，可以使用机器学习技术（例如[决策树](https://scikit-learn.org/stable/modules/tree.html)）构建针对特定打印机硬件的更准确的轻敲分类器。

### ADC 传感器选型

推荐的传感器特性：
- 至少 24 位分辨率
- SPI 通信
- 数据就绪（`DRDY`）引脚，用于无需 SPI 查询的样本就绪指示
- 可编程增益放大器，128× 增益以消除外部放大器
- SPI 复位指示，用于检测传感器重启（电气问题的常见表现）
- 可选采样率在 350 Hz 到 2 kHz 之间（低于 250 Hz 的速率需要更慢的探测速度并增加工具头力）
- 对于多个称重传感器的热床下方应用，使用所有通道同时采样的 ADC，例如 [ADS131M04](../Config_Reference.md#ads131m04)。多路复用 ADC 在通道切换后有建立延迟，并且读数存在时间模糊问题，会降低精度。

Klipper 的 `bulk_sensor` 和 `load_cell_probe` 基础设施简化了对新传感器的支持。传感器可以从 Python 配置，采样循环用 C 语言编写以最小化开销。

### 电源滤波

使用比 ADC 制造商规格建议更大的电容。ADC 数据手册假设低噪声电池供电环境。3D 打印机产生显著的 5V 总线噪声。在确定电容值之前，使用典型电源和活动步进驱动器测试传感器。

ADC 芯片和称重传感器应使用 LDO 驱动。开关降压转换器不适合此应用。

### 接地

ADC 芯片容易受到噪声和 ESD（静电放电）的影响。在芯片下方的第一层电路板上使用大面积接地平面。将芯片远离电源部分和 DC-DC 转换器。确保与 DC 电源的正确接地。

### HX711 和 HX717 注意事项

这些传感器很受欢迎但有局限性：

- Bit-bang（位脉冲模拟）通信的 MCU 开销较高；SPI 传感器更高效
- 无法向 MCU 通信复位事件，隐藏电气故障
- HX717（320 Hz）强烈优于 HX711（80 Hz）用于探测；将 HX711 探测速度限制在 2 mm/s
- HX711 采样率由硬件配置，不可通过软件配置；10 SPS 版本必须重新接线以支持 80 SPS
