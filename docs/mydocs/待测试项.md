- [ ] **1. 打印机启动无报错** — 配置 MPC_V2 控制器后重启，确认 Klippy 日志无异常，Numba 预热成功

- [ ] **4. 挤出扰动恢复** — 稳态下挤出耗材，温度跌落后应在合理时间内恢复到设定点
- [ ] **5. PGD 收敛性能** — 检查 `pgd_iterations_v2` 和 `pgd_converged_v2` 状态，确认伴随法正常收敛
- [ ] **6. 计算耗时对比** — 伴随法应比旧有限差分法明显更快（可通过日志观察）
- [ ] **7. `ekf_Q_scale` / `ekf_R_scale` 参数可调** — 在配置中修改这两个参数，确认 Klippy 正确读取且行为变化合理

## PR #6 — 稳态阶梯响应数据采集（挤出功能）

| 文件 | 改动 |
|------|------|
| `temp_data_collector.py` | `STEADY_STATE_CALIBRATE` 新增 `F`（挤出速度）和 `EXTRUDE_DURATION`（挤出时长）参数；稳态确认后才开始挤出（15s 延迟） |

### 测试项

- [ ] **8. 基础命令不传 F** — `STEADY_STATE_CALIBRATE HEATER=extruder TEMP_POINTS=50,100,150`，确认行为与之前一致（不挤出）
- [ ] **9. 传 F 参数启用挤出** — `STEADY_STATE_CALIBRATE HEATER=extruder F=300 EXTRUDE_DURATION=60`，确认挤出在稳态确认后约 15s 开始，持续 60s 后停止
- [ ] **10. F>0 但不传 EXTRUDE_DURATION** — 应挤出到稳态采集结束
- [ ] **11. 稳定性窗口逻辑** — 稳态判定使用 5s 窗口（而非之前的完整 `stable_duration`），确认稳态判定速度和数据采集时长分离
- [ ] **12. 日志输出** — 确认日志正确显示挤出状态（速度、距离、时长）
- [ ] **13. 挤出失败处理** — 在无挤出机或挤出机未就绪状态下执行，确认报错不崩溃
- [ ] **14. 数据文件完整性** — 采集完成后确认 CSV 数据包含挤出阶段的数据点
